## 📋 Описание

**OFFICE_AUTOMATION** — это комплексное решение для автоматизации различных офисных задач. Коллекция включает инструменты для работы с Excel, PDF, email, веб-скрапинга и многое другое. Идеально подходит для бухгалтеров, офисных работников и всех, кто хочет оптимизировать рутинные задачи.
---

## 🚀 Доступные инструменты

### 🎯 **OFFICE_ASSISTANT_IOCL.py**
**Универсальный офисный помощник**

Многофункциональное приложение для выполнения различных офисных задач:
- 📊 **Объединение Excel файлов** — слияние нескольких таблиц в одну
- ✂️ **Разделение Excel файлов** — разбиение больших таблиц на части
- 📄 **Объединение PDF** — слияние нескольких PDF документов в один
---

### 📈 **GSTR2A_Merging_Utility.py**
**Утилита для объединения GSTR2A файлов**

Комплексное решение для автоматического объединения всех файлов GSTR2A:
- 📁 Объединение Excel файлов GSTR2A за разные периоды
- 📊 Дополнительный анализ данных
- 📋 Детальная отчетность

**Как использовать:**
1. Подготовьте Excel файлы GSTR2A за нужные периоды
2. Запустите скрипт
3. Получите объединенный файл с анализом

---

### 📧 **Automating_Email_Part_1.py**
**Массовая рассылка email через Gmail (Часть 1)**

Отправка массовых email-сообщений нескольким получателям через Gmail.

**Особенности:**
- 📨 Отправка на множество адресов
- 📝 Настройка темы и содержимого
- 🔐 Безопасная авторизация через Gmail

---

### 📧 **Automating_Email_Part_2.py**
**Массовая рассылка email через Gmail (Часть 2)**

Улучшенная версия с автоматизацией через Excel:
- 📊 Список получателей хранится в Excel файле
- 📎 Указание вложений для каждого получателя
- ⚡ Полностью автоматизированная отправка

**Отличия от Части 1:**
- В Части 1 нужно вручную вводить адреса получателей
- В Части 2 все данные берутся из Excel файла

---

### 📊 **Combine_excel.py**
**Объединение Excel файлов**

Простая программа для объединения различных Excel файлов в один.

**Рекомендация:** Перед запуском программы посмотрите видео-туториал.

---

### 🔍 **Compare_Excel.py**
**Сравнение версий Excel файлов**

Сравнение двух разных версий одного Excel файла для выявления изменений.

**Применение:**
- Отслеживание изменений в документах
- Контроль версий
- Аудит данных

---

### ✍️ **Digitally_Signing_Multiple_Pdf.py**
**Цифровая подпись нескольких PDF файлов**

Автоматическая цифровая подпись множества PDF документов без ручного вмешательства.

**Технология:**
- Использует модуль `pyautogui` для автоматизации повторяющихся действий
- Полностью автоматизированный процесс
- Экономия времени при работе с большим количеством документов

---

### 📥 **gst_DOWNLOAD.py**
**Автоматическая загрузка GSTR-1 файлов**

> ⚠️ **Статус**: В разработке

Программа предназначена для автоматической загрузки файлов GSTR-1 для нескольких клиентов одновременно.

**Планируемый функционал:**
- Массовая загрузка GSTR-1 файлов
- Поддержка множества клиентов
- Автоматизация процесса

---

### ✅ **GSTIN_VALIDATOR_PYTHON.py**
**Валидатор GSTIN**

Короткий и лаконичный код для проверки валидности GSTIN (GST Identification Number).

**Возможности:**
- ✅ Проверка валидности GSTIN
- 📊 Определение текущего статуса:
  - Активен (Active)
  - Неактивен (Inactive)
  - Недействителен (Invalid)
  - Приостановлен (Suspended)
- 📋 Дополнительная информация:
  - Название компании
  - Адрес бизнеса

---

### 📊 **GSTR2A_Merging_Utility_Simple.py**
**Упрощенная версия утилиты объединения GSTR2A**

Облегченная версия утилиты для объединения GSTR2A файлов.

**Отличия от полной версии:**
- ❌ Без дополнительного анализа
- ✅ Простое объединение данных
- 📑 Результат в 4 отдельных листах:
  - B2B
  - B2BA
  - CDNR
  - CDNRA

---

### 📚 **Part5_OS_&_GLOB.py**
**Изучение модулей OS и GLOB**

Обучающий скрипт для изучения различных аспектов работы с модулями `os` и `glob` в Python.

**Что изучается:**
- Работа с файловой системой
- Поиск файлов по паттернам
- Управление путями и директориями
